# Produto SaaS — Studio Bolsas como produto vendável

Trilha de transformar o sistema do ateliê em um produto que outros ateliês/marcas comprem.

## Decisões a estruturar
- **Posicionamento** — o que é o produto, para quem (ateliês, costureiras, pequenas confecções?), qual dor resolve.
- **Concorrência** — quem já existe nesse espaço, preço deles, lacunas.
- **Modelo de receita** — assinatura mensal/anual, planos, freemium? Preço-alvo.
- **Custo e margem** — custo de Firebase/infra por cliente, ponto de equilíbrio.
- **Produto** — o que já está pronto, o que falta para virar multi-cliente (multi-tenant, cadastro, cobrança).
- **Go-to-market** — como conseguir os primeiros clientes; ateliê da Lisandra como caso de sucesso.
- **Jurídico** — termos de uso, política de privacidade (LGPD), contrato de assinatura.

## Próximos passos sugeridos
1. Definir o cliente-alvo e a proposta de valor em uma frase.
2. Pesquisar concorrentes e faixas de preço de mercado.
3. Modelar custo por cliente vs. preço → validar se o negócio fecha.
4. Mapear o que falta no app para atender mais de um cliente.
