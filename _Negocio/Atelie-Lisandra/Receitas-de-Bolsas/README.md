# Receitas de Bolsas ("receitas de bolo")

Acervo de construção das bolsas do ateliê. Cada modelo tem um arquivo próprio com **foto (link), descritivo, lista de compras e técnica**.

## Como usar
- 1 arquivo `.md` por modelo (ex.: `Bolsa-Meia-Lua-Bicolor.md`).
- Fotos em `fotos/` (salvar a imagem do link e nomear igual ao modelo).
- `Indice-Receitas.xlsx` — planilha-índice com nome, data, status, custo e links.

## Modelos
| Arquivo | Modelo |
|---|---|
| `Bolsa-Meia-Lua-Bicolor.md` | Bolsa meia-lua bicolor (creme + marinho) |
| `Bolsa-Bucket-Bicolor-Argolas.md` | Bolsa bucket/saco bicolor (bege + marinho), alças de argola |
| `Clutch-Wave-Fecho-Madeira.md` | Clutch em ponto onda com fecho de madeira (receita completa/testada) |

_Ao criar um novo modelo: adicione o `.md`, a foto e uma linha na planilha._
